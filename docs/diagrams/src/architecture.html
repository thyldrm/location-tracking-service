Location Tracking Service: runtime view

Hot path

POST /locations touches Redis (rate limit) and Kafka only. PostgreSQL is not on this path, so a database outage does not stop ingestion.

Cold path

The worker turns ~10,000 pings/s into a few transitions/s. Only a transition reaches PostgreSQL, in one transaction with its outbox event.

Read side

GET /areas and GET /logs read PostgreSQL directly with keyset pagination.
