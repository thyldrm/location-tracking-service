From ping to log entry

Two latencies

The client waits for the Kafka ack only (p99 target 50 ms). The entry becomes visible in GET /logs after the worker transaction (p99 target 1 s).

Most pings stop early

If the area set did not change, the worker updates Redis and nothing else: the OPT fragment is skipped.

Offsets

Offsets are committed after a batch completes, so a crash replays pings; idempotent writes absorb them.
